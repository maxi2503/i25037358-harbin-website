哈尔滨两页旅游网站 / Discover Harbin

1. 解压后，双击 index.html 即可查看首页。
2. 第二页是 explore.html；两页共用 style.css。
3. 在 VS Code 中打开整个文件夹即可修改。页面使用简单英文，没有视频，没有外部字体或脚本依赖。
4. 图片为真实照片，使用 Wikimedia 原图网络链接，需要联网显示。图片作者、来源和许可链接见页面底部。
5. 上传 GitHub 时，上传本文件夹里面的所有内容，让 index.html 直接位于仓库最外层。不要只上传 ZIP。
6. 在仓库 Settings > Pages 选择 Deploy from a branch、main、/(root)，然后保存。

修改提示：
文字：在两个 HTML 文件中查找对应英文。
颜色：修改 style.css 开头的 :root 颜色变量。
字体：修改 style.css 中的 font-family。
图片：修改 HTML 的 img src，也可以下载照片放入 images 文件夹并改为本地路径。保留真实照片并更新署名。
